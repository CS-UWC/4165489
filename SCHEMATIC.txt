================================================================
  BOARDS USED
================================================================

  node1, node2, node4 : ESP32-WROOM-32 DevKit V1 (38-pin)
  node3               : Arduino Nano (USB serial to gateway)

  ESP32 pin reminder (viewed from top, USB at bottom):
    3.3V is on the BOTTOM RIGHT of the board.
    VIN (5V) is on the BOTTOM LEFT of the board.
    They are on OPPOSITE sides - do not mix them up.

  Only ADC1 pins may be used for analog reads while Wi-Fi is active.
  On this board that means GPIO 32-39 (ADC2 is unavailable with Wi-Fi).

================================================================
  NODE 1 - ESP32 + DHT11 + MQ-131
================================================================

  ESP32 pin        Sensor pin      Notes
  ------------------------------------------------------------
  3.3V (right)  -> DHT11 VCC       3.3V
  GND           -> DHT11 GND       Ground
  GPIO 4        -> DHT11 DATA      Digital

  VIN (left)    -> MQ-131 VCC      5V (must use VIN)
  GND (left)    -> MQ-131 GND      Ground
  GPIO 34       -> MQ-131 AOUT     Analog, input-only pin

  Notes:
  - Bare DHT11 (4-pin chip) needs a 10k pull-up from DATA to VCC.
    Modules include the pull-up already.
  - MQ-131 needs a 60 second warm-up on first power-on.
  - MQ-131 AOUT can reach 5V, above the ESP32 GPIO limit of 3.3V.
    Use a divider, e.g.:

        AOUT -- 10k --+--> GPIO34
                      |
                     20k
                      |
                     GND

================================================================
  NODE 2 - ESP32 + SOUND + LIGHT
================================================================

  ESP32 pin        Sensor pin      Notes
  ------------------------------------------------------------
  3.3V (right)  -> Sound VCC       3.3V
  GND           -> Sound GND       Ground
  GPIO 35       -> Sound AOUT      Analog, input-only pin

  3.3V (right)  -> Light VCC       3.3V
  GND           -> Light GND       Ground
  GPIO 32       -> Light AOUT      Analog (ADC1)

  Notes:
  - Generic analog microphone and LDR modules. Adjust the on-board
    potentiometer for sensitivity.
  - For a bare LDR: 3.3V -> 10k -> GPIO32, LDR from GPIO32 to GND.

================================================================
  NODE 3 - ARDUINO NANO + HC-SR04 + KY-025 REED SWITCH
================================================================

  Nano pin         Sensor pin      Notes
  ------------------------------------------------------------
  D5            -> HC-SR04 TRIG    Output
  D6            -> HC-SR04 ECHO    Input
  D7            -> Reed DO         Digital (HIGH = magnet)
  A0            -> Reed AO         Analog (0-1023, 10-bit)
  5V            -> Sensor VCC     As required by modules
  GND           -> Sensor GND     Common ground with ESP32 boards

  Important:
  - This node has NO Wi-Fi stack. It sends semicolon-delimited frames over
    USB serial at 115200 baud; node3_bridge.py on the gateway parses them and
    publishes iot/node3/data.
  - DIST below 5 cm or a -1 echo timeout is treated as a sensor fault, not a
    real measurement. The last valid reading is retained.
  - reed_v is not emitted; only reed_ao (10-bit) and the boolean reed state.

  Serial frame format:
    NODE=3;DIST=<cm>;PROX=<label>;REED=<magnet|clear>;REEDAO=<0-1023>;

================================================================
  NODE 4 - ESP32 + AHT20 + LDR (AMBIENT LIGHT)
================================================================

  ESP32 pin        Sensor pin      Notes
  ------------------------------------------------------------
  3.3V (right)  -> AHT20 VCC       3.3V
  GND           -> AHT20 GND       Ground
  GPIO 21       -> AHT20 SDA       I2C data (Wire default)
  GPIO 22       -> AHT20 SCL       I2C clock (Wire default)

  3.3V (right)  -> LDR VCC         3.3V
  GND           -> LDR GND         Ground
  GPIO 34       -> LDR AOUT        Analog (ADC1, 12-bit 0-4095)

  Notes:
  - Wire.begin() uses the default I2C pins, so no explicit SDA/SCL define.
  - analogReadResolution(12) gives a 0-4095 raw light value.
  - light_v = raw * (3.3 / 4095), rounded to two decimals in the payload.
  - Thresholds: temperature > 35 C and raw light > 3000 emit network alerts.

================================================================
  POWER SUMMARY
================================================================

  Node   Sensor             Voltage   ESP32/board pin
  ------------------------------------------------------------
  node1  DHT11              3.3V      3.3V (right)
  node1  MQ-131             5V        VIN (left)
  node2  Sound              3.3V      3.3V (right)
  node2  Light              3.3V      3.3V (right)
  node3  HC-SR04 + reed     5V/3.3V   Nano (USB powered)
  node4  AHT20              3.3V      3.3V (right)
  node4  LDR                3.3V      GPIO34

  Use a separate 5V/1A USB supply per node for permanent deployment.
  Keep VIN (5V) wiring separate from the 3.3V rail.

================================================================
  MQTT TOPICS
================================================================

  iot/node1/data     node1 -> broker   temp, humidity, ozone, ...
  iot/node2/data     node2 -> broker   sound, light, ...
  iot/node3/data     bridge -> broker  distance, reed_ao, ...
  iot/node4/data     node4 -> broker   temp, humidity, light, light_v, ...
  iot/nodeX/command  broker -> node    PING / STATUS
  iot/network/status nodes -> broker   online / alive announcements
  iot/network/message nodes -> broker  peer alerts

================================================================
  ARDUINO IDE SETUP
================================================================

  ESP32 (node1, node2, node4):
    Boards Manager URL:
      https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
    Board: ESP32 Dev Module
    Upload speed 115200, flash 80MHz, mode QIO, default 4MB scheme.
    Libraries: PubSubClient, DHT sensor library (+ Adafruit Unified Sensor),
               ArduinoJson, Adafruit AHTX0.

  Arduino Nano (node3):
    Board: Arduino Nano, processor ATmega328P (Old Bootloader if needed).
    Upload speed 115200 to match node3_bridge.py.
    No extra libraries needed for the current sketch.

  If upload fails on ESP32, hold BOOT during upload and release once it starts.
  A "brownout detector" error usually means a poor USB cable - try another.
