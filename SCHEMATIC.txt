  ESP32-WROOM-32 PINOUT (as seen from TOP, USB at bottom)

  LEFT SIDE (top to bottom)         RIGHT SIDE (top to bottom)
  ──────────────────────────         ──────────────────────────
  EN                                 GPIO23
  GPIO36  (input only / SensVP)      GPIO22
  GPIO39  (input only / SensVN)      GPIO1   (TXD0)
  GPIO34  (input only)               GPIO3   (RXD0)
  GPIO35  (input only)               GPIO21
  GPIO32                             GPIO19
  GPIO33                             GPIO18
  GPIO25                             GPIO5
  GPIO26                             GPIO17  (TXD2)
  GPIO27                             GPIO16  (RXD2)
  GPIO14                             GPIO4
  GPIO12                             GPIO2   (onboard LED)
  GND                                GPIO15
  GPIO13                             GND
  D2  (flash — avoid)                3.3V    ◄── right side 3.3V
  D3  (flash — avoid)                GND     ◄── right side GND
  CMD (flash — avoid)
  VIN  (5V from USB)   ◄── left side bottom
  GND                  ◄── left side bottom

  IMPORTANT:
  - 3.3V pin is on the BOTTOM RIGHT of the board
  - VIN (5V) pin is on the BOTTOM LEFT of the board
  - They are on OPPOSITE sides — do not mix them up

================================================================
  BREADBOARD TIPS FOR ESP32-WROOM-32
================================================================

  The ESP32-WROOM-32 is wide and spans most of a standard
  400-point breadboard leaving very little space on each side.

  SOLUTION 1 — 830-point breadboard (recommended)
    Fits the ESP32 in the middle with rows free on both sides.

  SOLUTION 2 — Jumper wires to free rows
    Run male-to-male jumper wires from blocked ESP32 pins
    to empty rows further along the breadboard, then
    connect sensors to those rows.

  SOLUTION 3 — Use the power rails
    3.3V ──► breadboard (+) rail
    GND  ──► breadboard (-) rail
    Sensors draw power from the rails — frees up pin rows.
    WARNING: Keep VIN (5V) wiring SEPARATE from the 3.3V rail.

  SOLUTION 4 — Direct Dupont wires (skip breadboard)
    Use female-to-female Dupont jumper wires directly from
    sensor module pins to ESP32 pins. Works well for modules
    that have their own PCB board.


================================================================
  ARDUINO IDE SETUP FOR ESP32-WROOM-32
================================================================

  STEP 1 — Add ESP32 board support URL
    File → Preferences
    Paste into "Additional Boards Manager URLs":
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
    Click OK

  STEP 2 — Install ESP32 boards
    Tools → Board → Boards Manager
    Search: esp32
    Install: esp32 by Espressif Systems
    Wait for install to complete

  STEP 3 — Select board
    Tools → Board → ESP32 Arduino → ESP32 Dev Module

  STEP 4 — Upload settings
    Tools → Upload Speed       → 115200
    Tools → Flash Frequency    → 80MHz
    Tools → Flash Mode         → QIO
    Tools → Partition Scheme   → Default 4MB with spiffs
    Tools → Core Debug Level   → None
    Tools → Port               → COMx (Windows)
                                 /dev/ttyUSB0 (Linux/Mac)

  STEP 5 — Install libraries
    Sketch → Include Library → Manage Libraries

    Library                   Author
    ──────────────────────────────────────────
    PubSubClient              Nick O'Leary
    DHT sensor library        Adafruit
    Adafruit Unified Sensor   Adafruit
    ArduinoJson               Benoit Blanchon

    When installing DHT sensor library:
    Click "Install All" when prompted for dependencies
    This installs Adafruit Unified Sensor automatically

  STEP 6 — Upload sketch
    Connect ESP32 via USB
    Click Upload in Arduino IDE
    If upload fails: hold BOOT button on ESP32 while
    clicking Upload, release once upload starts

  COMMON ERRORS:
  ┌─────────────────────────────────────────────────────┐
  │ "Failed to connect to ESP32"                        │
  │  → Hold BOOT button during upload                   │
  │                                                     │
  │ "Port not found" / no COM port showing              │
  │  → Install CP2102 USB-to-UART driver:               │
  │    silabs.com/developers/usb-to-uart-bridge-vcp-drivers│
  │                                                     │
  │ "Brownout detector was triggered"                   │
  │  → Bad USB cable, try a different one               │
  │  → Use a powered USB hub                            │
  │                                                     │
  │ DHT sensor returns NaN                              │
  │  → Check wiring, add 10kΩ pull-up on DATA pin       │
  │  → Increase delay between reads to 2000ms           │
  └─────────────────────────────────────────────────────┘
